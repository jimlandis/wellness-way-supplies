# The Wellness Way Supplies – member portal (DRAFT)

**DRAFT – local files only. Do not publish, deploy or upload.** Static HTML/CSS/JS. Everything
(login session, cart, orders, facility info) is stored in the browser's `localStorage`.
There are no network calls and no emails. Membership is by invitation, so there is no sign-up.
One demo account is checked client-side in `js/demo-auth.js`. The typed password is never stored.

## Run it locally
Recommended (so `data/prices.json` is read directly):

    cd /workspace/wellnessway/site
    python3 -m http.server 8765 --bind 127.0.0.1
    # open http://127.0.0.1:8765/index.html

You can also open `index.html` straight from disk (file://). Browsers block `fetch()` of local
JSON there, so the site falls back to `js/prices.js`, which is a copy of `prices.json` (see below).

## Edit prices (one file)
All prices live in **`data/prices.json`**, keyed by SKU, in US dollars per unit (band, unit, roll):

    {
      "WWS-SB-YEL": null,      <- null = shows "Price TBD"
      "WWS-SB-RED": 12.5,      <- a number = used for line totals and subtotal
      ...
    }

* `null` → the product, cart and checkout show **Price TBD**, and any total that includes it shows **Total TBD**.
* A number ≥ 0 → line totals and the subtotal compute automatically.
* Use plain numbers (no `$`, no quotes). Keep the file valid JSON (no comments, no trailing commas).
* After editing, run `python3 tools/sync_prices.py` from this folder. It checks the values and refreshes
  `js/prices.js` so file:// mode shows the same prices. Over http.server the JSON is used directly.
* Prices are copied into an order when it is submitted, so old orders keep the prices they were placed at.
* Every price is `null` in this draft. No prices have been set.

## Pages
`index.html` (public landing) · `login.html` · `members/catalog.html` · `members/product-*.html` (3) ·
`members/cart.html` · `members/checkout.html` · `members/confirmation.html` · `members/orders.html` ·
`members/account.html`. Member pages redirect to the login page when nobody is logged in.

## Rebuild
Pages are generated by `/workspace/wellnessway/build/gen.py` (`python3 build/gen.py`). It keeps any
prices already in `data/prices.json` and adds new SKUs as `null`.
Account → "Clear demo data in this browser" resets the cart, orders and facility info.
